# База знания лаборатории: с чего начать

## Что это

Общая память лаборатории, в которую пишут не люди, а их агенты, и из которой они же читают.
Записи связаны между собой в цепочку, и у каждого рода свой инструмент:

| Что | Чем записывается | Что означает |
|---|---|---|
| утверждение | `create_hypothesis` | то, что мы считаем верным и что можно опровергнуть |
| прогон | `record_experiment` | эксперимент, заведённый ради проверки конкретного утверждения |
| измерение | `record_evidence` | число, вышедшее из прогона |
| доказательство | `record_derivation` | то, чем теория опирается вместо прогона |
| правило | `propose_decision` | решение лаборатории и измерения, на которых оно стоит |

Плюс библиотека: больше пятисот прочитанных статей, разобранных примерно на восемь тысяч
отдельных утверждений с дословными цитатами. Своего знания около сорока проектов, семисот
утверждений, шестисот прогонов и восьмисот измерений. Числа растут каждый день.

## Зачем это вам

Обычный поиск отдаёт куски текста, и дальше вы читаете их сами. Здесь поиск отдаёт связанные
записи: спросили про прогрев — получили и утверждение о нём, и прогон, который его проверял, и
число, которое из прогона вышло, даже если в самом числе слова «прогрев» нет. Такие записи
помечены в выдаче как пришедшие по связям.

Второе: агент, который начинает работу с поиска по базе, не переоткрывает уже проверенное и видит,
чем закончились чужие попытки, включая опровергнутые.

## Подключение

Ссылка приходит письмом от ведущего, с его личного адреса: своего почтового домена у базы пока
нет. Ссылка одноразовая и действует неделю, обращайтесь с ней как с паролем. Если письмо не
дошло — попросите ведущего, он передаст ссылку иначе.

Откройте ссылку и нажмите **Показать ключ**. Экран выдачи сразу покажет обе команды подключения с
уже подставленным ключом — проще скопировать оттуда. Ниже то же самое на случай, если экран
закрыт.

**Codex.** Переменную допишите в свой профиль оболочки (`~/.zshrc` или `~/.bashrc`), иначе она
пропадёт вместе с окном терминала:

```
export LAB_KNOWLEDGE_KEY=ВАШ_КЛЮЧ
codex mcp add lab-knowledge --url https://<адрес базы>/mcp \
  --bearer-token-env-var LAB_KNOWLEDGE_KEY
```

**Claude Code.** По умолчанию сервер привязывается к текущей папке; чтобы он был доступен везде,
добавьте `--scope user` в конец:

```
claude mcp add --transport http lab-knowledge https://<адрес базы>/mcp \
  --header "Authorization: Bearer ВАШ_КЛЮЧ" --scope user
```

Проверить: `codex mcp list` или `claude mcp list` должны показать `lab-knowledge` и признак
подключения. Если нет — для Codex проверьте, что переменная видна в новом окне терминала, для
Claude Code перезапустите сессию. Ключ один и работает сразу для всех ваших инструментов; нужен
ещё — попросите новую ссылку, прежний продолжит работать.

Отдельным письмом придёт приглашение в приватный репозиторий `brain-lab-research/lab-knowledge` —
это код самой базы и внутренние заметки, оно от GitHub и приходит само.

Точный адрес приходит вместе с приглашением: здесь он не напечатан, потому что репозиторий
публичный, а база — нет. Домена у неё пока нет, поэтому адрес выглядит непривычно, но сертификат
настоящий.

## Первые десять минут

Спросите базу словами, как спросили бы коллегу:

- «что у нас известно про прогрев и нужен ли он»
- «Muon и спектральная норма: что мы пробовали»
- «какие есть измерения по памяти в безградиентной оптимизации»

Смотрите не только на первые попадания, но и на записи, помеченные как пришедшие по связям.
Первый поиск после простоя занимает секунд десять, дальше быстрее; случайный `502` бывает, просто
повторите.

Дальше откройте статью из библиотеки и посмотрите, на какие утверждения она разобрана.

## Как записать своё

Проект вы заводите сами, ждать ведущего не нужно. Дальше цепочка идёт по порядку: прогон нельзя
завести без утверждения, измерение — без прогона. У каждой записи обязателен
`idempotency_key`: любая строка, по которой повтор вызова не создаст вторую копию.

```
create_project(name="Sandbox Ivanov", theme_slug="lab-general",
               idempotency_key="sandbox-ivanov")

create_hypothesis(project_id=…, statement="Прогрев можно сократить вдвое без потери качества.",
                  falsification_criteria="на трёх сидах итоговый loss хуже более чем на 0.02",
                  idempotency_key="hyp-1")

record_experiment(hypothesis_id=…, protocol="три сида, LLaMA 30M, одинаковый бюджет шагов",
                  idempotency_key="exp-1")

record_evidence(experiment_id=…, summary="Сокращённый прогрев дал loss 3.21 против 3.20.",
                kind="measurement", metrics=[{"name": "final_loss", "value": 3.21}],
                idempotency_key="ev-1")
```

Если название проекта не латиницей, добавьте `slug`. В чужой проект запись отвечает
`project access is read-only`: это правило, а не поломка. Читать можно всё — стен между проектами
при чтении нет.

## Что служба действительно отклоняет

Отказ приходит текстом, который называет причину. Читайте его, а не повторяйте то же самое.

Проверяется жёстко:

- **утверждение о чужой статье без дословной цитаты из её текста**. Цитата сверяется с сохранённым
  разбором статьи; если текста статьи в базе нет, запись пройдёт, но будет помечена как
  несверенная. Там же отклоняются обрывки вместо формулировок — строка таблицы, половина формулы,
  пункт нумерованного списка, — и эмпирическое утверждение без величины;
- **измерение без числа**, если род записи обещает величину. `kind: "metric"` или
  `"measurement"` без заполненного `metrics` не пройдёт, и отказ назовёт выход: взять число,
  записать наблюдение через `record_journal` или назвать род, который величины не обещает —
  `artifact`, `manuscript`, `diagnostic`. Правило появилось 04-09-2026, и по нему десять прежних
  записей переехали в журнал;
- **переход состояния, которого нет в цепочке** утверждения, и **доказательство с безымянным
  пробелом**.

Остальное — договорённость лаборатории, а не запрет службы, и держится на людях: у утверждения
должен быть **достижимый** критерий опровержения. Поле обязательно, но его смысл никто не
проверяет, и «хуже во всех случаях» пройдёт, не закрыв ничего.

## Полная карта базы

Эта страница нужна для первой записи. Когда станет непонятно, почему сущностей больше, чем
здесь перечислено, что означают связи и какие роды записей есть кроме пяти основных, читайте

список того, что сейчас неудобно.

## Что стоит знать

Кто записал строку, база берёт из вашего ключа — это вы. Каким инструментом, она определяет сама
по тому, чем он представился при подключении: Codex, Claude Code, агент на сервере. Расписываться
и придумывать себе имя не нужно.

Служба живёт в одном процессе, поэтому тяжёлый запрос может ненадолго её занять. Если она совсем
не отвечает — скажите ведущему.

## Куда писать, если что-то не так

Ведущему, включая мелочи: непонятный отказ, странную выдачу, неработающую ссылку. Всё это ещё
никто не видел снаружи.
